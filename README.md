# 无限题 · 福建高考刷题

> 不是题库，是题厂。针对福建高考的自动出题刷题工具，每次都是新题，永远做不完。

## ✨ 核心特性

- **参数化出题引擎**：内置 84 个参数化模板（数/物/化/生/英/语），每次自动生成全新题目，答案经验算器校验 **100% 正确**，杜绝背答案
- **针对福建高考命题规律建模**：如实借鉴调研成果——
  - 语/数/外：新课标Ⅰ卷（全国命题）
  - 物理/化学/生物：福建省自主命题卷（75分钟/100分）
- **智能出题**：按科目+知识点+难度+题型一键生成，薄弱知识点优先
- **错题反哺**：答错自动入错题本，薄弱点专项突破，支持间隔复习
- **试卷生成**：按福建高考各科真实卷面结构生成模拟卷，支持限时+在线作答+打印
- **学情分析**：正确率、学习趋势、知识点掌握度雷达
- **知识图谱**：考点掌握度可视化，一键开始训练
- **AI 辅导**：自行导入任意 OpenAI 兼容 API（智谱GLM免费版/DeepSeek/通义/Kimi等），针对福建高考专项答疑
- **全离线可用**：纯前端，本地数据，PWA 可安装；全部免费

## 🚀 使用

**方式一：直接打开**
打开 `app/index.html`（或部署到 GitHub Pages 后访问线上地址）。

**方式二：本地启动**
```bash
cd app
node server.cjs --port 3114
# 访问 http://localhost:3114
# server 内置 AI 代理（/api/ai），可服务端持有 API Key（环境变量 AI_API_KEY）
```

**配置 AI（可选）**：在「我的 → AI 参数设置」选择供应商并填入 API Key（支持智谱GLM免费 flash 版），即可使用 AI 讲解错题/知识点。
